# Pretty Table

Program konsol yang mencetak jadual Pokémon dan jenisnya dengan pakej PrettyTable.

## Apakah ini?

Hari ke-16 kursus Udemy *100 Days of Code: The Complete Python Pro Bootcamp*, tugasan tentang menambah pakej Python daripada PyPI. Fungsi `create_table` membina `PrettyTable` dengan lajur Pokemon Name dan Type, dan `main` mencetaknya. Barisnya ialah Pikachu (Electric), Squirtle (Water) dan Charmander (Fire). PrettyTable ialah satu-satunya kebergantungan semasa larian.

## Apa yang diajar oleh latihan ini

- Memasang dan mengimport pakej daripada PyPI, Python Package Index
- Mengisytiharkan kebergantungan semasa larian dalam `pyproject.toml`
- Membina jadual dengan kelas `PrettyTable`
- Menulis ujian automatik pytest, dan menjalankan linter dan penyemak jenis yang ketat

## Apa yang dilakukannya

- Jadual nama dan jenis Pokémon dicetak sebagai teks
- Nama fungsi tugasan `create_table` dan `main`
- Tajuk lajur dan baris disimpan dalam pemalar
- Jalankan sebagai `python -m pretty_table` atau dengan arahan `pretty-table`
